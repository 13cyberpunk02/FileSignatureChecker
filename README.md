# Проверка файлов и подписей

WPF приложение для проверки соответствия файлов и их электронных подписей между XML документом и файловой системой.

## Возможности

- ✅ Проверка наличия файлов по имени и контрольной сумме CRC32
- ✅ Проверка электронных подписей (.sig файлов)
- ✅ Обнаружение файлов с измененными именами
- ✅ Поиск незагруженных файлов с подписями
- ✅ Детальная статистика проверки
- ✅ Экспорт результатов в текстовый файл
- ✅ Экспорт результатов в файл Excel
- ✅ Современный Material Design интерфейс

## Использование

### 1. Выбор файлов
- Нажмите **"Обзор"** рядом с полем "XML файл" и выберите XML файл с описанием документов
- Нажмите **"Обзор"** рядом с полем "Директория с файлами" и выберите директорию с файлами для проверки

### 2. Выполнение проверки
- Нажмите кнопку **"Выполнить проверку"**
- Дождитесь завершения процесса проверки

### 3. Просмотр результатов
- В таблице отобразятся все проверенные файлы с соответствующими статусами:
  - 🟢 **Успешно** - файл и подпись найдены, контрольные суммы совпадают
  - 🟠 **Предупреждение** - файл найден, но есть несоответствия (имя или контрольная сумма)
  - 🔴 **Ошибка** - файл или подпись не найдены
  - 🔵 **Информация** - файл найден в директории, но не указан в XML

### 4. Дополнительные действия
- **Экспорт** - сохранить результаты проверки в текстовый файл
- **Очистить** - очистить результаты и начать новую проверку
- **Открыть в проводнике** - открыть расположение файла в Windows Explorer

## Структура XML файла

```xml
<Document>
  <DocType>99.99</DocType>
  <DocName>Название документа</DocName>
  <DocNumber>№ 01-47-23697/23</DocNumber>
  <DocDate>2023-05-03</DocDate>
  <DocIssueAuthor>Автор</DocIssueAuthor>
  <File>
    <FileName>документ.pdf</FileName>
    <FileFormat>pdf</FileFormat>
    <FileChecksum>3FC10558</FileChecksum>
    <SignFile>
      <FileName>документ.pdf.sig</FileName>
      <FileFormat>sig</FileFormat>
      <FileChecksum>29C68BA0</FileChecksum>
    </SignFile>
  </File>
</Document>
```

## Логика проверки

### Проверка файлов:
1. Поиск файла по точному имени
2. Если не найден - поиск по контрольной сумме CRC32
3. Сравнение контрольных сумм для найденных файлов

### Проверка подписей:
1. Поиск .sig файла по точному имени
2. Если не найден - поиск по контрольной сумме CRC32
3. Сравнение контрольных сумм для найденных подписей

### Поиск незагруженных файлов:
- Анализ всех файлов в директории
- Выявление файлов с подписями, не указанных в XML

## Поддерживаемые форматы файлов

- PDF (.pdf)
- Excel (.xls, .xlsx)
- Word (.doc, .docx)
- GGE (.gge)
- Подписи (.sig)
