# 🚀 Быстрый старт

## Что это?

WPF приложение для автоматической проверки соответствия файлов и их электронных подписей (.sig) между XML документом и файловой системой.

## ⚡ Быстрая установка

### Шаг 1: Установите .NET 10.0
Скачайте и установите **.NET Desktop Runtime 10.0** с официального сайта:
👉 https://dotnet.microsoft.com/download/dotnet/10.0

### Шаг 2: Распакуйте проект
Распакуйте архив `FileSignatureChecker.zip` в любую папку

### Шаг 3: Откройте проект
- **Visual Studio 2026**: Откройте файл `FileSignatureChecker.csproj`
- **Командная строка**: 
  ```bash
  cd FileSignatureChecker
  dotnet restore
  dotnet run
  ```

## 📋 Как использовать

1. **Выберите XML файл** - нажмите "Обзор" в первой строке
2. **Выберите директорию** с файлами - нажмите "Обзор" во второй строке
3. **Нажмите "Выполнить проверку"** - подождите завершения
4. **Просмотрите результаты** в таблице

## ✅ Что проверяется?

- ✔️ Наличие файлов по имени
- ✔️ Совпадение контрольных сумм CRC32
- ✔️ Наличие подписей (.sig файлов)
- ✔️ Файлы не указанные в XML

## 🎨 Цветовая индикация

- 🟢 **Зеленый** - всё в порядке
- 🟠 **Оранжевый** - предупреждение (несовпадение имени/суммы)
- 🔴 **Красный** - ошибка (файл не найден)
- 🔵 **Синий** - информация (файл не загружен в XML)
